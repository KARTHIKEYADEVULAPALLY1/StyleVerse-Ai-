## 📖 Overview

StyleVerse AI is a cutting-edge AI-powered fashion platform that revolutionizes the way users discover, compare, and try on clothing. Combining the latest in artificial intelligence, computer vision, and real-time price comparison, StyleVerse AI delivers a premium fashion shopping experience that feels like a high-end boutique meets futuristic technology.

---

## ✨ Features

### 🧠 AI Search Engine
- Natural language search across millions of fashion products
- Rotating smart placeholders for inspiration
- Voice and image search capabilities (UI ready)
- Trending search suggestions

### 👗 Virtual Try-On
- Upload your photo for AI-powered body analysis
- Interactive 3D avatar with rotation and zoom controls
- Customize clothing options in real-time
- AI Fit Score with detailed metrics (shoulder fit, sleeve length, body shape, comfort, trend, color match)

### 🤖 AI Stylist
- Personalized outfit generation based on:
  - Style Profile (Streetwear, Minimalist, Formal, Bohemian, Athleisure, Vintage)
  - Occasion (Casual, Office, Date Night, Party, Wedding, Travel)
  - Color Palette (Neutrals, Earth Tones, Cool Blues, Bold & Bright, Monochrome)
- AI styling tips and suggestions

### 💰 Smart Price Comparison
- Real-time price scanning across major retailers
- Amazon, Myntra, Ajio, Flipkart comparison
- Delivery time estimation
- Best price highlighting with savings calculation

### ❤️ Smart Wishlist
- Price drop notifications
- Stock availability tracking
- One-click buy
- Share functionality

### 🎨 Fashion-Forward Design
- Custom clothes hanger logo with animated gradient
- Vibrant pink/violet/cyan color palette
- Premium typography (Italiana, Cormorant Garamond, Montserrat)
- Glass morphism effects with dark/light mode
- 3D holographic mannequin (Three.js)
- Smooth animations (Framer Motion)
- Magnetic buttons and tilt cards

## 📦 Installation

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/KARTHIKEYADEVULAPALLY1/StyleVerse-Ai-.git

# Navigate to project
cd StyleVerse-Ai-

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The development server will start at `http://localhost:5173/`
